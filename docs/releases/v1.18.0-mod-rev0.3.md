## Executive Summary

Release **v1.18.0-mod-rev0.3** hardens ESP32-S3 hardware stability, RadioLib ISR concurrency, USB-Serial/JTAG host communication, and on-device RF observability across all 5 MeshCore roles (`companion_radio_ble`, `companion_radio_usb`, `repeater`, `room_server`, `kiss_modem`), packaged into clean, host-path-anonymized unified `0x0` images with `SHA256SUMS.txt`.

## What's New in `v1.18.0-mod-rev0.3`

* **Power Sequencing, ESD Isolation & WFI Sleep Safety (`NMEPD420Board`):** Enables `SX126X_POWER_EN` (`IO47`) before SPI CS setup at boot; isolates `SCLK`/`MOSI`/`RESET` (`INPUT`) and latches `NSS` `LOW` prior to cutting `IO47` in Deep Sleep to stop SPI ESD back-powering. Replaces OPI-PSRAM `esp_light_sleep_start()` lockups with interruptible `20 ms` WFI slices (`sleep()`) paired with `USB_SERIAL_JTAG` SOF host tracking (`isUsbPowered()`, `5 s` holdoff) and TWDT feeding.
* **Non-Blocking Battery ADC & AHT20 State Machines:** Converted runtime ADC settling/averaging (`BattAdcState`, `setAdcMultiplier()`) and 45 s AHT20 background I2C refreshes into non-blocking state machines while keeping `TEMP_CTL` (`IO40`) stably powered in active mode.
* **Thread-Safe RadioLib State & `crc_err` / `spi_err` Telemetry Split:** Guarded shared `state` / `DIO1` ISR transitions with ESP32 `portMUX_TYPE` critical sections (`portENTER_CRITICAL(_ISR)`), hardened `CustomSX1262Wrapper::setParams()` RX transitions (`setRxBoostedGainMode()`), enabled `SX126X_REGISTER_PATCH=1`, and split CRC vs SPI counters via `StatsFormatHelper`.
* **Cross-Role `RF HEALTH` UI & microSD Libpcap Logger:** Added the shared `RF HEALTH` E-Paper telemetry page across Companion, Repeater, and Room Server alongside `NMEPD420SDLogger` writing `/mesh_capture.pcap` (`DLT_USER0=147`) and `/mesh_rf.log` with `sd status|retry|on|off|clear|pcap-test|ring-test` CLI (Repeater/Room) and `Enter` mount retry (Companion).
* **160 MHz CPU, Windows USB CDC & KISS Sync:** Raised CPU frequency to 160 MHz, silenced verbose `GxEPD2` init serial logs, added post-flash CDC re-latch wait + 64-byte ZLP avoidance on Repeater/Room CLI, synced `KissModem` startup radio macros, and restored `-fmacro-prefix-map` / `-ffile-prefix-map` anonymization across all outputs.

## Flashing & Verification

```bash
# Verify SHA256 checksums before flashing
sha256sum -c SHA256SUMS.txt

# Flash unified image to 0x0 (replace COM15 and role filename as needed)
python -m esptool --port COM15 --baud 921600 --chip esp32s3 --after watchdog-reset write_flash 0x0 MeshCore-NM-EPD-420-BW-companion_radio_ble-v1.18.0-mod-rev0.3.bin
```

On Windows, run `.\flash.ps1` or double-click `flash.bat`. For EU868 869.618 MHz (10% duty cycle), configure `set af 9` via CLI.

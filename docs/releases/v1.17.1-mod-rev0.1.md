# RockBase NM-EPD-420 MOD `v1.17.1-mod-rev0.1`

**Target Hardware:** RockBase NM-EPD-420-BW (`ESP32-S3R8`, `16 MB` Flash, `8 MB` Octal PSRAM, `4.2"` `400x300` B/W E-Paper `SSD1683`, Semtech `SX1262` LoRa, `AHT20`)  
**Upstream Base:** MeshCore v1.17.1 (`d9296435`)

---

## Executive Summary

Initial **RockBase NM-EPD-420 MOD** release for the **RockBase NM-EPD-420-BW** companion radio board, delivering critical memory/watchdog fixes, full native 400x300 E-Paper support, AHT20 telemetry, non-linear LiPo voltage-to-percentage estimation, physical button deep-sleep wakeups, and zero quiescent power leakage.

## Detailed Changelog

* **Safety & Reliability Fixes:** Fixed multi-byte UTF-8 out-of-bounds read in `translateUTF8ToBlocks()`, fixed 5-second `USER` (`IO45`) BLE bond clearing by erasing NVS pairing bonds cleanly at startup, replaced unsafe `esp_task_wdt_deinit()` with an adaptive 15 s TWDT (`esp_task_wdt_reconfigure()`), removed conflicting UART pins (`IO43`/`IO44`) in `pins_arduino.h`, and guarded `BOOT`/`USER` button polling races.
* **Native `400x300` E-Paper Engine:** Expanded canvas from 128x128 margins to full `200x150 @ 2.0x` (`400x300` native `GYE042A87`), powered down charge pumps (`display.powerOff()`) after every update, added `CRC32` frame caching, automatic full refresh every 30 partials, dynamic vertical centering (`NM_DY`), 8-row `RECENT` view, and streamlined carousel pages.
* **AHT20 Environmental Sensing:** Power-gated AHT20 integration (`TEMP_CTL` `IO40`) displaying live temperature/humidity on Home and Radio pages (`600s` interval + `Enter` manual refresh).
* **LiPo Battery ADC & OCV Curve:** Added ESP32-S3 priming read before `ADC_11db` attenuation, `20 ms` divider settle (`IO43`), 8-sample averaging, live header percentage, and a 12-point non-linear LiPo OCV discharge curve (`4.20V = 100%`, `3.82V = 50%`, `3.27V = 0%`).
* **Deep Sleep & Message Preview:** Implemented `EXT0` (`BOOT IO0` LOW) and `EXT1` (`DIO1 IO14` HIGH) wakeup with peripheral rail isolation, expanded Unread payload buffer to 161 bytes with UTF-8 boundary truncation, and eliminated the 1 Hz Unread refresh storm using static `"now"` timestamps (`<60s`).

**Target Hardware:** RockBase NM-EPD-420-BW (`ESP32-S3R8`, `16 MB` Flash, `8 MB` Octal PSRAM, `4.2"` `400x300` B/W E-Paper `SSD1683`, Semtech `SX1262` LoRa, `AHT20`)  
**Upstream Base:** MeshCore v1.18.0 (`81dbae5`, protocol version 14)  
**Compare:** [`v1.17.1-mod-rev0.3...v1.18.0-mod-rev0.1`](https://github.com/v3n0m3n0/MeshCore-NM-EPD-420-MOD/compare/v1.17.1-mod-rev0.3...v1.18.0-mod-rev0.1)

## Executive Summary

Release **v1.18.0-mod-rev0.1** upgrades the RockBase NM-EPD-420-BW firmware from MeshCore v1.17.1 to **MeshCore v1.18.0** (protocol v14) and ships the first complete **5-role suite** (`companion_radio_ble`, `companion_radio_usb`, `repeater`, `room_server`, `kiss_modem`), preserving all board-level E-Paper, PSRAM, sensor, and power optimizations.

## Firmware Roles Included

| Role | Binary (`0x0`) | Primary Use Case |
| --- | --- | --- |
| **Companion Radio BLE** | `MeshCore-NM-EPD-420-BW-companion_radio_ble-v1.18.0-mod-rev0.1.bin` *(alias: `MeshCore-NM-EPD-420-BW-v1.18.0-mod-rev0.1.bin`)* | Mobile companion via BLE + WiFi station + CLI rescue |
| **Companion Radio USB** | `MeshCore-NM-EPD-420-BW-companion_radio_usb-v1.18.0-mod-rev0.1.bin` | Desktop / Web client companion via USB CDC |

| **KISS Modem** | `MeshCore-NM-EPD-420-BW-kiss_modem-v1.18.0-mod-rev0.1.bin` | Headless serial KISS TNC radio bridge |

## What's New in `v1.18.0-mod-rev0.1`

* **Upstream v1.18.0 Synchronization:** Integrated MeshCore v1.18.0 (`protocol v14`), `CMD_RUN_CLI_COMMAND` over BLE/WiFi/Serial, decoupled `MyMesh::Listener` UI notifications, and portable build fixes.
* **Zero-Hop Repeater Discovery (`HomePage::DISCOVERY`):** Integrated interactive node discovery into the native 400x300 E-Paper carousel (`row_step = 14`, UTF-8 transliteration, `discover: press Enter` prompt).
* **Dynamic WiFi & BLE Coexistence:** Enabled runtime WiFi station connectivity (`ENABLE_WIFI_INTERFACE`), reconnect handling, and Home-page IP status display alongside BLE.
* **Interactive Multi-Role Flashers:** Upgraded `flash.ps1` and `flash.bat` with interactive role menus covering all 5 compiled roles.
* **Preserved `-MOD` Hardware Layer:** Kept Core 0 asynchronous 16 MHz FSPI E-Paper task, 256-frame Octal PSRAM offline queue, shared HSPI microSD CS (`IO7`) isolation, non-blocking AHT20/ADC telemetry, 5 s `USER` bond wipe, and `+22 dBm` TX limit.
